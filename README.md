# Healthcare Patient Analysis Dashboard | Power BI

Created an interactive Healthcare Patient Analysis Dashboard using Power BI to analyze patient demographics, health indicators, treatment plans, diagnosis, and follow-up patterns.

### Key Features
- Patient demographics and diagnosis analysis
- Average Age, BMI, Heart Rate & Cholesterol
- Treatment and gender distribution
- Age group and follow-up analysis
- Interactive slicers
- Decomposition Tree

### Tools Used
Power BI | Power Query | Data Cleaning | Data Visualization
